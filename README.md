# Spotify++

## Features
- Horizontal Swipe Gestures (Play Next/Prev and Navigate to Next/Prev Page)
- Slim navbar

## Build:
``` bash
bun i
bun run build
spicetify config extensions spotify-pp.js
spicetify apply
```

## Hot Reloading (only affter building once):
``` bash
bun run watch
spicetify watch -le
```
