# Spotify++

## Features
- Horizontal Swipe Gestures (Play Next/Prev and Navigate to Next/Prev Page)

## Build:
``` bash
bun i
bun run build && spicetify apply
```
or
``` bash
bun run watch
spicetify watch -le
```
